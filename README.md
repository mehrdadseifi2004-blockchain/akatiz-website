# HAREB Website V3

Dark cinematic artist website built with Next.js 16.3.1, React 19.2 and TypeScript.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Notes
- EN / FA language switch
- Persian fonts are bundled under public/fonts
- Current artwork uses YouTube thumbnails as temporary imagery
- Replace the image URLs later with official high-resolution photography
